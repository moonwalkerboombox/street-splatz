# Legacy card art

The first, flat version of the 100 cards (520 x 720): the generator `generate_splatz.py` and its SVG output in `images/`.
Kept for reference only. Nothing in the build, the site or the tests reads this folder.

Do not run `generate_splatz.py`. The real cards are drawn by `assets/brawler/` from the fixed traits in `assets/metadata/`.
Run `npm run cards` at the repo root to rebuild them.
